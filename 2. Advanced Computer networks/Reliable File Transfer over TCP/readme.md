For Single TCP Connection File Transfer
    1. change directory to Single Socket directory
    2. open two terminal
    3. on first terminal run command "python server.py"
    4. on second terminal run command "python client.py"
    5. As you can see enter the path for file - Copy the path of file which you want to send.
    6. Paste path and enter.
    7. You can see the recieved file in recieved_file folder.
